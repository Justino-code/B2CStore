## **6.3. Lições Aprendidas**

### **6.3.1. Técnicas**
1. **Laravel + Livewire** é uma combinação poderosa para projetos acadêmicos e MVP comerciais
2. **Tailwind CSS** acelera desenvolvimento frontend mas requer disciplina para manter consistência
3. **Arquitetura modular** desde o início facilita manutenção e evolução
4. **Testes automatizados** são críticos mesmo em projetos acadêmicos
5. **Documentação viva** (atualizada com código) previnte desalinhamentos

### **6.3.2. De Mercado (Angola)**
1. **Mobile-first não é opção, é obrigação** (72% acesso via smartphone)
2. **Confiança é barreira maior que tecnologia** (desconfiança em pagamentos online)
3. **Logística é desafio crítico** (infraestrutura fora dos centros urbanos)
4. **Educação digital é necessária** (usuários precisam aprender a comprar online)
5. **Pagamentos locais são essenciais** (Multicaixa, cash on delivery dominantes)

### **6.3.3. Acadêmicas**
1. **Projetos interdisciplinares** exigem coordenação entre áreas de conhecimento
2. **Documentação contínua** previnte perda de conhecimento
3. **MVP realista** > projeto ambicioso não terminado
4. **Validação com usuários reais** (mesmo limitada) é insubstituível
5. **Metodologias ágeis** adaptadas funcionam bem em projetos acadêmicos

## **6.4. Limitações do Projeto**

### **6.4.1. Limitações Técnicas**
1. **Pagamentos Simulados:** Integração real com gateways angolanos não implementada
2. **Escala Limitada:** Não testado com carga real de milhares de usuários
3. **Logística Simplificada:** Cálculo de fretes básico, não integrado com transportadoras
4. **Internacionalização Básica:** Apenas português, sem suporte a línguas nacionais
5. **SEO Limitado:** Otimização básica para motores de busca

### **6.4.2. Limitações de Pesquisa**
1. **Dados Secundários:** Análise de mercado baseada principalmente em dados publicados
2. **Validação Limitada:** Usabilidade testada com grupo pequeno/não representativo
3. **Foco Geográfico:** Principalmente Luanda, menos atenção ao interior
4. **Horizonte Temporal:** Análise baseada em dados até 2023
5. **Segmentação Simplificada:** Consumidor tratado como bloco homogêneo em alguns aspectos

## **6.5. Recomendações para Implementação Real**

### **6.5.1. Prioridades para Produção**
1. **Integração de Pagamentos Reais:**
   - Multicaixa Express (primeira prioridade)
   - Carteiras digitais locais (Sodiba, eTumba)
   - Cash on delivery com confirmação digital

2. **Parcerias Logísticas:**
   - Acordos com 2-3 transportadoras para cobertura nacional
   - Sistema de pickup points em lojas parceiras
   - Rastreamento em tempo real

3. **Otimizações de Performance:**
   - CDN para imagens (Cloudflare, AWS CloudFront)
   - Cache agressivo com Redis
   - Otimização de banco de dados

4. **Conformidade Legal:**
   - Lei de Proteção de Dados (Lei 22/11)
   - Regulamentação de e-commerce angolana
   - Termos de serviço e política de privacidade específicos

### **6.5.2. Roadmap de Evolução (6-18 meses)**

**Fase 1: Consolidação (0-6 meses)**
- [ ] Integração pagamentos reais
